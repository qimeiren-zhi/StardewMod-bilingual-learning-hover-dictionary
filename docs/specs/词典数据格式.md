# 词典数据格式说明

> 本文档定义「离线词典构建脚本」与「mod 运行时」之间的数据契约，使二者可独立开发、独立测试、独立替换。

## 1. 定位

- **消费者**：mod 运行时（`DictionaryData.cs`），启动时一次性加载，悬停时查词。
- **生产者**：离线构建脚本（`tools/build-dict`），从 ECDICT 生成。
- **契约**：本文件所定义的词典文件格式。双方只认格式、不认实现。

## 2. 文件规范

| 项 | 值 |
|---|---|
| 文件名 | `dictionary.tsv` |
| 位置 | mod 的 `assets/` 目录（运行时为 `Mods/<Mod名>/assets/dictionary.tsv`） |
| 编码 | UTF-8 无 BOM |
| 行尾 | LF（`\n`），一行一条词条 |
| 分隔符 | 制表符 `\t` |
| 表头 | 无（首行即数据） |

## 3. 字段定义（当前 v1）

每行 3 列，依次为：

| 列 | 字段 | 类型 | 说明 | 约束 |
|---|---|---|---|---|
| 0 | word | 字符串 | 英文单词（查词键） | 非空；不含 `\t`/`\n`；建议小写；**全局唯一** |
| 1 | translation | 字符串 | 词性 + 中文释义 | 非空；形如 `n. 收获, 成果`；义项以 `, ` 分隔；不含 `\t`/`\n` |
| 2 | tag | 字符串 | 难度标签 | 可空；空格分隔；空 = 基础词（低于阈值，不显示） |

## 4. tag 取值

`gk`、`cet4`、`cet6`、`ky`、`toefl`、`ielts`、`gre`（ECDICT 中另有 `zk` 等）。一个词可含多个标签，空格分隔。等级过滤（P5）按「命中任一所选等级即显示」处理。

## 5. 运行时约定

- 查找：**忽略大小写**的精确匹配（word 作字典键）。
- 未命中：显示「未收录」（或按 F13 不显示气泡，P3 确定）。
- 加载失败（文件缺失）：记日志告警，所有查词返回未命中，不影响 mod 其它功能。

## 6. 生成流程（离线）

1. 输入：ECDICT `ecdict.csv`（列：`word,phonetic,definition,translation,pos,collins,oxford,tag,bnc,frq,exchange,detail,audio`）。
2. 脚本：`tools/build-dict`，用法：
   ```
   dotnet run --project tools/build-dict -- <input.csv> <output.tsv> [maxFrq]
   ```
3. 规则：
   - 纳入条件：`tag` 非空，或 `frq ∈ (0, maxFrq]`（默认 maxFrq=30000）。
   - 释义取首行：去掉 `translation` 字段中字面 `\n` 之后的其它词性行。
   - 字段内 `\t`/`\r`/`\n` 一律替换为空格。
4. 输出：`dictionary.tsv`。

## 7. 版本演进计划

| 版本 | 变更 | 阶段 |
|---|---|---|
| v1（当前） | `word \t translation \t tag`，词性+释义合并 | Spike / P3 |
| v2 | 分离 `pos` 与 `translation` 两列；释义收敛到 1~2 个义项 | P6 词典构建 |
| v3 | 加入「游戏词表精筛」（仅游戏用词 + 常用词子集），缩小体积 | P6 词典构建 |

> 说明：版本升级需同步更新 `DictionaryData.cs` 的解析逻辑与 `build-dict` 的生成逻辑；旧版本数据文件不向后兼容时，应在文件名或字段里体现版本。
