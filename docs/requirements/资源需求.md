## 6. 资产授权与处理细则

### 6.1 字体（R5）
- 授权：SIL OFL 1.1 —— 允许嵌入、再分发与商业使用；**不得单独售卖字体文件**。
- **保留名条款**：子集化属「修改」，修改版**不得使用保留名**（「悠哉 / Yozai」），需改名（如 `LearningHand.ttf`）。
- 体积：子集化至词典实际用字，预计 1~3 MB；随附 OFL 许可证原文 + 版权声明（LXGW / 原 Y.OzVox 等）。

### 6.2 词典（R6）
- ECDICT 授权 MIT，可自由使用与再分发；产物为精简 CSV（`word, pos, translation, tag` 等）。
- 等级过滤依赖 `tag` 字段（见《需求规格说明》6.2）。

### 6.3 游戏内资产复用（R10a / R10b）
- 运行时读取游戏贴图属正常 mod 行为，不构成再分发，无授权问题。

### 6.4 自制资产（R10c，若采用）
- 描边星小图为自制像素画，随 mod 打包，自持版权。
