# 星露谷双语学习 Mod · 需求规格说明（冻结版）

> 版本：v1.0（冻结版） · 冻结日期：2026-11-20
> 状态图例：✅ 已冻结 ｜ ⬜ 非冻结项（实现期可调）

---

## 0. 目标

当《星露谷物语》游戏语言为英文时，玩家在 NPC 对话中可查看**单个英文单词**的**词性 + 中文释义**（以覆盖式气泡呈现），并可把想记的单词**主动加入个人生词本**，最终**导出为文档**复习。

---

## 1. 范围

### 1.1 MVP（本期必须）
- 仅覆盖 **NPC 对话**（`DialogueBox`）。✅ F12
- 生词本**按存档隔离**存储。✅ F15

### 1.2 本期明确不做
- 不覆盖信件 / 物品提示 / 任务日志 / 事件过场等其它文本面。✅ F12
- **不联网查词**：未收录词**不显示气泡**。✅ F13
- 不做**词频累加**统计。✅ F6
- 不做**游戏内查看 / 复习单词本**（用导出文档代替）。✅ F16
- **不使用 Content Patcher**，不修改游戏原生字体或内容资产。✅ R9

## 3. 关键交互规则（实现约束）

### 3.1 触发
- hover：鼠标停留在单词上时显示气泡。✅ 0.5.0 已实现，是唯一触发方式。
- ⬜ Alt+点击：**未实现，本期不做**（理由见 §9-1）。
- 触发方式配置项未开放（F10 现状见 §4）。

### 3.2 命中检测与打字机门槛
- 英文分词以空格为界，命中前去除两侧标点。
- 解析后的最终文本需先处理对话命令（`^` 换行、`@` 玩家名、`#`、`$` 系列指令等），再分词。
- **打字机门槛**：仅当 `characterIndex >= 当前句全文长度`（文字已完整显示）时才执行命中检测与查词。文字仍在逐字显示时：hover 不出气泡、Alt+点击不查词。
- 依赖游戏内置行为：点击对话框在打字机未完成时**直接跳过打字机、显示全文**（无需额外实现）。

### 3.3 气泡显示与隐藏
- 气泡为**可交互控件**（内含星标），因此：
  - **隐藏条件**：鼠标**同时离开「单词、气泡、桥接矩形」**即**立即隐藏（0 延迟）**；鼠标进入气泡区域时气泡保持显示（桥接矩形覆盖词与气泡间的 4px 间隙，见 §9-2）。
  - 样式可配：气泡风格 `Default` / `Sandy's Notes`（0.5.0）；字号、颜色、透明度未开放为配置项。

### 3.4 星标与点击分层
- 气泡内含**星标开关**（toggle）：点亮铱星 = 加入生词本；再次点击 = 取消收藏并移出。
- **点击处理顺序**：
  1. 先判断点击是否落在气泡内的星标上；
  2. 是 → 切换星标、写入/移除生词本，并**吞掉本次点击**（不触发对话翻页）；
  3. 否 → 放行给游戏默认逻辑（翻页 / 跳过打字机）。
- 已在生词本中的词，再次查词时气泡内的星标保持点亮状态。

### 3.5 语言校验
- 启动与运行期间校验当前语言代码为英文才启用；非英文时模块整体停用（不绘制、不响应）。

### 3.6 美术风格与资产复用
- **气泡背景**：0.5.0 使用自制 PNG（`assets/bubble_default.png` / `bubble_sandy.png`）以 `IClickableMenu.drawTextureBox` 九宫格绘制，四角清晰、边框自适应；原「复用 `LooseSprites/dialogueBox` 九宫格」方案保留为纹理缺失时的运行时回退（见 §9-3）。
- **星标·点亮态**：复用游戏内置**铱星图标**（`LooseSprites/Cursors` 中的物品品质星，约 8×8），按需放大绘制，像素风放大保持风格统一。
- **星标·未点亮态**：默认采用**运行时着色/描边**——对原铱星 sprite 做深灰/半透明着色，并在四周偏移 1px 绘制深色底实现描边（零自制资产）；若描边效果不足，再补自制一张 8×8（或 16×16）描边星小图。
- 上述均为**运行时读取游戏已有贴图**，不改动、不分发游戏资产，无需 Content Patcher、无授权问题。

## 5. 数据与文件格式

### 5.1 生词本（内部状态，按存档隔离）
存储位置：SMAPI `Helper.Data`（`Mods/<Mod名>/data/<存档id>.json`）。

```json
{
  "words": [
    {
      "word": "harvest",
      "pos": "v./n.",
      "translation": "收获；收割",
      "sentence": "I should harvest these crops before they wilt.",
      "firstSeen": { "year": 1, "season": "Spring", "day": 5 }
    }
  ]
}
```

- `pos`（词性）为**已确认的记录字段**（气泡已显示词性，顺带写入）。
- `season` 内部存英文键，显示时映射：Spring→春、Summer→夏、Fall→秋、Winter→冬；展示格式 `第{year}年{season}第{day}日`。

### 5.2 导出（显式动作）

| 格式 | 用途 | 内容 |
|---|---|---|
| CSV / TSV | Excel / 表格 | 列：word, pos, translation, sentence, firstSeen |
| Markdown | 阅读友好单词本 | 按上述字段排版 |
| Anki `.apkg` | 间隔重复复习 | 正面 = 单词（可含例句），背面 = 词性 + 释义 |

## 6. 词典与等级过滤

### 6.1 词典构建（离线，一次性脚本）
- **主体词表**：提取游戏全部英文文本（`Content/Characters/Dialogue/*.json`、`Content/Data/*.json`、`Content/Strings/*.json`）→ 分词去重 → 得到游戏实际用词表（预计数千词）。
- **释义来源**：从 [ECDICT](https://github.com/skywind3000/ECDICT) 中筛出上述词表的词条。
- **兜底**：并入一个通用常用词子集（前 2~3 万词）。
- 说明：游戏本身只有句子级本地化（`en ↔ zh-CN`），**没有单词级词典**，故释义一律来自 ECDICT。

### 6.2 等级过滤（语义 + 标签映射）
- **过滤语义**：**只对达到所选难度等级的单词显示气泡**（低难度常见词不打扰）。
- 一个词可携带多个等级标签，命中任一所选等级即显示；无标签的基础词视为「低于阈值」，不显示。

| 用户等级 | ECDICT `tag` |
|---|---|
| 高中 | `gk`（高考） |
| 四级 | `cet4` |
| 六级 | `cet6` |
| 考研 | `ky` |
| TOEFL/雅思 | `toefl` / `ielts` |
| GRE | `gre` |

## 7. 技术实现要点（约束行为，非功能需求）

- **Harmony 补丁点**：`DialogueBox.performHoverAction`（hover 命中）、`DialogueBox.receiveLeftClick`（Alt+点击与星标点击分层）。
- **双层绘制**：英文用游戏原生字体绘制（不动）；中文释义气泡用自带 TTF + FontStashSharp 在独立覆盖层绘制。
- **字体**：✅ [悠哉字体 Yozai](https://github.com/lxgw/yozai-font)（OFL 1.1，备选：小赖字体）。子集化后**必须改名**（OFL 保留名条款），并随 mod 附带 OFL 许可证 + 版权声明。
- **坐标换算**：命中判断与绘制统一使用游戏 UI 缩放后的坐标系（`pixelZoom` / `uiViewport`）。

## 9. 实现偏离记录（0.5.0）

> 冻结后经实机验证做出的调整。与上文原始描述冲突时，**以本节与源码为准**；目的：不再把这些当 bug 回修。

| # | 原需求 | 0.5.0 实际 | 理由 | 代码位置 |
|---|---|---|---|---|
| 1 | F1：hover + Alt+点击（可分别开关） | 仅 hover | hover 已覆盖全部查词场景；Alt+点击需额外拦截点击并判断修饰键，易与「星标点击吞掉」「翻页/跳过打字机」冲突，收益低 | `WordOverlay.cs` `OnHover` / `OnClick` |

| 3 | §3.6：复用对话九宫格纹理 | 自制 `bubble_default.png` / `bubble_sandy.png` | 原纹理为深色底，中文深色字对比不足；自制浅色纸张底更易读，且可切换风格 | `WordOverlay.cs` `Draw`、`BubbleRenderer.cs` |
| 4 | §4：字号 / 颜色 / 隐藏延迟 / 触发方式可配 | 仅 5 项（GMCM 4 项 + `config.json` 的 Lookup key） | 避免配置项膨胀；实际需求集中在快捷键与气泡风格 | `ModConfig.cs`、`ModEntry.cs` `RegisterConfigMenu` |
| 5 | F10 / §6.2：词典等级过滤 | 移除 | ECDICT `tag` 是考纲等级而非常见度，空 tag 占 52.8%，会误杀常见词（`channeled`/`pelican`）；查词是主动行为，无需过滤 | `docs/ai/DECISIONS.md` 决策 4 |
| 6 | F12：仅 NPC 对话 | 已扩展物品 tooltip（F1 知识卡片） | 玩家最常读的文本面；重放原生 tooltip 成本低、观感一致 | `KnowledgeCardMenu.cs`、`docs/ai/DECISIONS.md` 决策 5 |

## 10. 后续需求记录（2026-11-23，阶段 3b-1 实机反馈）

> 非当前阶段 bug，记录待排期；不与 §9 的「已实现」混用。

| # | 需求/限制 | 现象 | 根因/位置 | 期望 | 优先级 |
|---|---|---|---|---|---|
| 1 | **连字符/复合词分词** | 悬停 `coop-dwelling` 不出气泡（整词不在词典） | 切词目前按空白切分，`coop-dwelling` 被当成一个 token；`WordOverlay.NormalizeWord` / `BuildSpriteFontHits` 的分词 | 命中前按 `-`、`'`、`’` 等拆分为可查子词（或先查整体再拆），且不改变对话查词既有行为 | 中 |
| 2 | **卷轴居中标题可查词** | 木匠菜单蓝图描述上方的建筑标题（`Coop` / `Barn` 等）不能查词 | 标题走 `SpriteText.drawStringWithScrollCenteredAt`（`drawBGScroll=0`），被 `TextCapture.RegisterSpriteText` 的 `drawBGScroll != -1` 闸门跳过；同类的订单板 `ChooseOne` 横幅、底部 Choose/Move/Paint/Demolish 也如此 | 新增「scroll 居中文本」布局（居中起点 + 卷轴宽度 + 换行），按文本面逐步接入；不要为单个菜单硬编码 | 中 |
| 3 | **同形多义词义项选择** | 日历悬停 `Fall` 显示「落下，爱上」而非「秋天」；`saw` 显示「锯子」而非「看见」 | 词典按拼写精确匹配，条目为单条释义，无 POS/上下文消歧（`BUG_PATTERNS.md` #16、#22） | 语境/词性消歧，或对季节/月份等高频专名维护覆盖表（轻量方案优先） | 低（影响面小但观感明显） |
| 4 | **商店 tooltip 随光标抢焦点**（3b-4 用户反馈，可接受） | 商店里悬停商品名出气泡后，鼠标移入气泡时游戏 tooltip 会按光标位置切到下一行商品 | 扩展气泡是只读覆盖层，不拦截/抑制菜单的 `performHoverAction`；游戏每帧按鼠标坐标重算 hover 行 | 可在气泡显示期间临时抑制菜单 hover（需 hook，风险较高），或保持现状（用户认为可接受） | 低 |
